
The model codes are in Python and the model can be run using either example.py Python-code or example.ipynb Jupyter notebook. 
Running the model requires some python libraries, which can be installed with:

Windows:
pip install tensorflow==2.14.0
pip install pandas
pip install librosa
pip install numpy==1.26.0
pip install resampy

Linux:
pip install tensorflow==2.14.0
pip install pandas
pip install librosa

Additionally convolutional base of BirdNET-Analyzer v2.4 is needed and can be obtained from: 
https://zenodo.org/records/15050749
